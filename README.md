# GollumFit

GollumFit is an open-source framework developed by IceCube for performing binned-likelihood, high energy, neutrino telescope analyses. In particular, GollumFit handles the fitting of monte carlo to data where the monte carlo may be parametrized by a large number of nuisance parameters such as detector efficiencies and neutrino fluxes.

For details on the code, installation, usage, and examples, please visit the official documentation at [https://docs.icecube.aq/golemfit/main/index.html](https://docs.icecube.aq/golemfit/main/index.html).
