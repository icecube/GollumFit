# GollumFit

GollumFit is an open-source framework for performing binned-likelihood, high-energy neutrino telescope analyses. It fits Monte Carlo simulations to observed data across a large number of nuisance parameters — detector efficiencies, neutrino fluxes, ice properties, and hadronic interactions — using the LBFGSB minimization algorithm.

Full documentation, including installation instructions, code structure, and usage examples, is available at:
